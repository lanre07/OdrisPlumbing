

# OdrisPlumbing 

A responsive plumbing business website built with HTML, CSS, and JavaScript. The website presents plumbing services, showcases project images, and provides contact information for potential customers.


##  About the Project

Odris Plumbing is a business website designed to present plumbing services in a clear and professional way. It helps visitors explore available services, view project images, learn about the business, and get in touch.

##  Features

- Home page with a hero section
- About page introducing the business
- Services page describing plumbing solutions
- Gallery showcasing plumbing projects
- Contact page for customer enquiries
- Frequently Asked Questions (FAQ) section
- Responsive layout for different screen sizes

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

##  Website Pages

- Home
- About
- Services
- Gallery
- Contact
